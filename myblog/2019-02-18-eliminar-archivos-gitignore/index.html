Eliminar archivos trackeados

Posted on February 18, 2019

Este tutorial lo hago para tener un lugar donde buscar los comandos.

Paso 1

Hacer un commit de todos los cambios

De todo, incluyendo el .gitignore

Paso 2

Eliminar los archivos del índice

git rm -r --cached .
  • rm es para borrar
  • -r para que sea recursivo
  • El punto especifica que todos los archivos se van a eliminar. Para borrar solo algunos se los puede especificar con git rm –cached archivo.c

Paso 3

Agregar todo de nuevo

git add .

Paso 4

Hacer un commit con los cambios

git commit -m "arreglo .gitignore"
