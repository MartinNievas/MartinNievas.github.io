    Configuración de VimLaTexSuite

    04 February 2018

    Vamos a ver como podemos instalar un plugin bastante interesante que nos permite utilizar Vim para compilar archivos LaTex sin la necesidad de salir del mismo.

    Si tenemos instalado Vim,nos saltamos este paso, sino, podemos instalarlo con el siguiente comando (asumo que estamos en alguna versión de Ubuntu o derivados):

    sudo apt install vim

    Administrador de plugins

    Los administradores de plugins nos permiten trabajar mas fácil y de forma mas ordenada. En este caso utilizaremos Pathogen. Para instalarlo debemos hacer:

    mkdir -p ~/.vim/autoload ~/.vim/bundle
curl -LSso ~/.vim/autoload/pathogen.vim https://tpo.pe/pathogen.vim

    Si no tenermos instalado curl, podemos instalarlo haciendo:

    curl -LSso ~/.vim/autoload/pathogen.vim https://tpo.pe/pathogen.vim

    Ahora tenemos que hacer que vim al iniciar cargue Pathogen. Los archivos de configuración de Vim están en el archivo .vimrc. El mismo se encuentra en nuestra carpeta del \home. En caso de no tenerlo, crear uno vacío. Agregamos estas lineas al comienzo de nuestro ~/.vimrc con cualquier editor de texto:

    execute pathogen#infect()
syntax on
filetype plugin indent only

    VIM-LATEX-SUITE

    Ahora que ya tenemos instalado nuestro gestor de plugins vamos a instalar Vim-LaTexSuite:

    Primero necesitamos descargar los archivos de SourceForge

    Presionamos en descargar la última versión, y esto nos lleva a la página de descarga. El archivo descargado es “vim-latex-1.10.0.tar.gz”. Vamos a la carpeta de descargas y descomprimimos el archivo. Luego de descomprimir los archivos se genera una carpeta “vim-latex-version”. dentro de la misma encontramos los siguientes archivos:

    compiler/  doc/  ftplugin/  indent/  latextags*  ltags*  Makefile  Makefile.in  plugin/  README.md  vim-latex.metainfo.xml

    Copiamos los archivos a nuestra carpeta .vim en el home.

    Abrimos de nuevo el archivo .vimrc y agregamos:

    filetype plugin on
set grepprg=grep\ -nH\ $*
let g:tex_flavor='latex'
""Pueden agregarse mas, pero eso es lo básico

    Comocamos las siguientes lineas en el archivo ~/.vim/ftplugin/tex.vim (en caso de no existir el archivo, crearlo):

    "Identando el código queda mas presentable
set sw=2
" TIP: if you write your \label's as \label{fig:something}, then if you
" type in \ref{fig: and press  you will automatically cycle through
" all the figure labels. Very useful!
set iskeyword+=:

    Con esto ya tenemos todo listo para compilar LaTex desde Vim!

    COMO UTILIZAR

    Una guia completa está aquí… Pero resumiendo:

    1. Abrimos Vim en una terminal en una carpeta donde deseemos crear nuestro proyecto.
    2. Podemos crear un archivo LaTex simple o abrir un archivo ya creado. En este caso vamos a pegar un ejemplo sencillo foo.tex: 
      \documentclass[a4paper]{article}
\begin{document}
Probando :D
\end{document}

      Para compilar el archivo de LaTex en el modo normal de Vim presionamos

      ,ll

      Esto genera una serie de archivos foo.aux foo.log foo.pdf foo.synctex.gz

    Para ver el archivo PDF generado, en el modo normal

    ,lv

    Con eso terminamos la primera entrada del foro.
