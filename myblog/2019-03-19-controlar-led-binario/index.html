Controlar LED RGB con binario y arduino

Posted on March 19, 2019

En este ejemplo se mostrará como utilizar el código binario enviado a una placa arduino, mediante el puerto serie, para controlar un led RGB.

Materiales

  • Arduino (cualquiera puede funcionar)
  • Protoboard
  • Cables de conección
  • Resistencias de 220 ohm
  • LED RGB

El circuito es el que se muestra en la página de arduino.

Código para Arduino

get the code

Procedimiento

El procedimiento es básicamente conectar la placa a la computadora, abrir el programa descargado con el Arduino IDE y cargarlo a la placa.

Luego, abrir el monitor de puerto serie (ctrl+shift+m) y escribir 3 dígitos correspondientes a los colores. La velocidad del puerto debe estar configurada en 9600. Hay que tener en cuenta que los bits para prender los leds, trabajan en lógica negada, es decir, un 0 enciende el color correspondiente, y un 1 lo apaga.
