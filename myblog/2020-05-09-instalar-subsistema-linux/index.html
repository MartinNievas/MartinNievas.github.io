    Instalar subsistema de Linux en windows y herramientas de compilación

    Posted on May 9, 2020

    Video

    La primera parte está cubierta en éste video

    Tienen que seguir eso, hasta el minuto 2:18 (cuando reinicia). Luego de reiniciar, continuar con las imágenes de abajo:

    1. Buscar la tienda de microsoft

    2. En el buscador, poner ubuntu

    3. Buscar ubuntu 20.04

    4. Poner “no, gracias”

    5. Se empieza a instalar

    6. Esperamos…

    7. Ingresan su nombre de usuario (el que quieran)

    8. Crean una clave y listo!

    9. En la terminal (la ventana negra) escribimos: sudo apt install build-essential

    10. Se terminó de instalar (demora unos minutos)

    11. Tenemos que controlar que gcc esté instalado, para eso escribimos: gcc –version

    12. Ponemos clear para borrar la pantalla (también podemos presionar Ctrl+L)

    13. Con “ls” listamos los archivos que están en el directorio actual (en este caso no hay nada). Tenemos que bajar un programa…

    14. Escribimos: wget martinnievas.com/hello.c

    15. Borramos la pantalla con Ctrl+L y escribimos: gcc hello.c

    16. Se generó un programa “a.out”. Para ejecutarlo, ponemos: ./a.out

    Debería salir “Hello!” por la pantalla.

    Fin!
