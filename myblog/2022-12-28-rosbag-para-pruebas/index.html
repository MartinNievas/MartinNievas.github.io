Reproducir rosbag para pruebas

Posted on December 28, 2022

Pasos para ejecutar el rosbag en pruebas locales

Para evitar errores con el tiempo:

Transform [sender=/odom] Message removed because it is too old (frame=[/link_chassis], stamp=[1809237948.1498749182])
[WARN] [1456267968.1398749182, 1455437948.1494443182]: Detected jump back in time. Clearing TF buffer.

Hay que configurar el parámetro use_sim_time luego de lanzar el roscore:

roscore
rosparam set /use_sim_time true
roslaunch <launchfile.launch>
rosrun rviz rviz
rosbag play --clock --pause rosbag.bag
