Sistema de control para hexápodo utilizado en ambientes extremos

NO disponible


El objetivo del trabajo es diseñar e implementar el sistema de control para un hexápodo como el de la imágen de arriba. Los hexápodos son robots que tienen características especiales para desplazarse en terrenos con obstáculos y transportar carga. Existen diferentes formas de desplazamiento (como mueven las patas) para lo cual se deben mover de forma sincronizada los 18 servos presentes en el mismo. Se prefiere personas con conocimiento en Software Libre, particularmente en Linux ya que vamos a estar programando sobre ROS para la parte de control.





Objetivos

Entre los objetivos específicos podemos destacar:
  • Adaptar las bibliotecas disponibles para los diferentes patrones de desplazamiento
  • Trabajar junto al equipo de hardware para optimizar los algoritmos en base a las dimensiones

    • Requisitos

    El proyecto tiene mucho de diseño y programación, por lo que conocer C++ y Python es un plus. Dado que el proyecto será liberado al público, se prefiere que sea diseñado en software libre (KiCAD). Vamos a estar trabajando con ROS para la parte de control. El diseño se va a publicar en gitlab.
