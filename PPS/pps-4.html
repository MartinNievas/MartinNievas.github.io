El objetivo del trabajo es mejorar el diseño mecánico de un hexápodo que actualmente está disponible en internet. Los materiales del mismo serán en base a los requerimientos específicos de la aplicación. Se prefiere personas con conocimiento en Software de diseño Libre como ser FreeCAD, pero no es limitante. También se trabajará en el sistema de potencia para distribuir la energía a los servos y diferentes sensores montados sobre el hexa. También se trabajará en el sistema de control para generar diferentes formas de caminar junto al equipo de software.





Objetivos

Entre los objetivos a medir:
  • Rediseñar o mejorar la estructura actual
  • Confeccionar los planos para enviar a fabricar el diseño final
  • Trabajar junto al equipo de software para optimizar el sistema
  • Diseñar el sistema de alimentación (Determinar baterías y componentes de potencia)

    • Requisitos

    El proyecto tiene mucho de diseño y programación, por lo que conocer C++ y Python es un plus. Dado que el proyecto será liberado al público, se prefiere que sea diseñado en software libre (FreeCAD). Vamos a estar trabajando con ROS para la parte de control. El diseño se va a publicar en gitlab, y vamos a estar utilizando estrategias ágiles por lo que suma para el CV (pueden poner el link al tablero de canvas.
